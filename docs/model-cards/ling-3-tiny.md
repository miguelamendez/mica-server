# Ling 3.0 Tiny — Mica candidate

- Original: [inclusionAI/Ling-3.0-tiny](https://huggingface.co/inclusionAI/Ling-3.0-tiny), MIT. The publisher describes 7.9B total and 1.3B active parameters, with hybrid KDA/MLA attention and 128 routed experts.
- Publisher GGUFs: [inclusionAI/Ling-3.0-tiny-GGUF](https://huggingface.co/inclusionAI/Ling-3.0-tiny-GGUF), revision `01b850e29ed5b44e2b810160ff980a9bb353296f`. Mica registers Q4_K_M (4,823,894,944 bytes) and Q8_0 (8,408,187,808 bytes), each with a SHA-256 in the [manifest](../../config/model-manifests/ling-3-tiny.yaml). These are publisher quants, not Mica conversions.
- Engine: upstream `llama-cpp`, requiring the BailingMoE3 merge commit `373336672029b12e09f272bc027cc801345a3fd6` or a descendant. The coding profile selects Q4 on demand; Q8 is a registered alternative. Both still need direct and proxied inference checks.
- Declared context: 131,072 tokens in the original config. The Mac coding profile intentionally limits Ling to 7,168 input and 1,024 output tokens (8,192 total), one request, Q8 KV cache, one resident worker across the whole profile, and a 16 GiB unified-memory admission budget. Context-length support is not a claim that 131K fits this machine or avoids context degradation.
- Reasoning: thinking can be enabled or disabled in the chat template. A precise thinking-token budget is not currently certified in Mica. The original card recommends temperature 1.0, top-p 0.95, and top-k 20 for thinking mode.
- MLX: [rapid-mlx's Q4 conversion](https://huggingface.co/rapid-mlx/Ling-3.0-tiny-MLX-4bit) exists, but its card says it needs the separate `rapid-mlx` implementation; Mica's packaged `mlx-lm` engine has not been certified for this architecture. Community MLX Q8 variants exist but are not registered without a matching tested engine.
- Open validation: clean Q4/Q8 download, checksum, direct model load, Mica-proxied reasoning/coding/tool calls, Q4-versus-Q8 output checks, prefill/decode speed, long-context behavior, and peak memory. Provisional reservations are 8 GiB (Q4) and 12 GiB (Q8), not measurements.
